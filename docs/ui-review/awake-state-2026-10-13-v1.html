两个入口使用完全相同的名称
  • 保持 Mac 运行：主开关；防止系统休眠，合盖后后台任务继续运行。
  • 保持桌面可用（Computer Use）：在主开关生效的基础上，保持桌面会话可用，支持屏幕自动化。替换原“使用 Computer Use 等工具”。已勾选但主开关关闭时，两个入口均标注“待开启主开关”。
  • 开盖后自动锁定：沿用此前设置，在主开关和桌面可用模式均生效时，开盖触发系统锁定。
菜单用勾选状态，窗口用开关状态；名称、状态来源和说明一致。

电源说明建议：“电池供电时会增加耗电，长时间合盖运行建议连接电源。”当前代码没有仅限外接电源的条件，不写“必须连接电源”。本机合盖后拔电的实际行为尚未验证。

推荐行为与边界

  • 保留现有深色、绿色视觉，顶部固定高度的状态区提供命名稳定的“保持 Mac 运行”开关。缩减装饰性留白控制窗口高度；所有状态使用同一槽位，不因消息变化移动其他控件。草图省略下方原有卡片，不代表移除。
  • 同一状态模型用于主窗口和菜单栏；所有入口（菜单、键盘、CLI、定时器）变化均刷新窗口。窗口主开关沿用既有 CapsLock 切换和防休眠逻辑，避免产生相互竞争的开关。
  • 点击后立即呈现 pending 且禁重复提交；实际系统设置成功后才呈现 on/off。关闭失败不能显示“已关闭”。读状态失败不能默认 off。辅助输入权限故障与防休眠失败要区分，保留上次已确认状态及具体原因。
  • 主开关是运行状态，不新增会在启动时自动启用的持久化偏好。保持现有 CapsLock、自动关闭及开盖锁定语义；所有可选开关偏好保留。未启用的子功能在固定说明区标明暂未生效。
  • 原生开关提供无障碍名称、值、禁用状态，支持 Tab、Space；更新状态不抢焦点。不用闪烁动画，不仅靠颜色区分状态。
  • 菜单“切换 Caps Lock”改为与窗口同名的“保持 Mac 运行”，以勾选表示状态；定时器零时长文案“不自动关闭”，中文宽度需重新布局而非裁切。保留其他时长。
  • 边界：本次仅改状态显示与入口；不变更250ms开盖检测、不恢复更新器、不继续已停止的安全审查、不增加网络访问、不把参考应用代码引入项目。

文案修订 · 2026-10-13 · revision_requested → pending

用户指出“防止系统休眠”不足以涵盖合盖继续运行、避免合盖导致桌面会话不可用及 Computer Use 的用途。原推荐“防止系统休眠”保留在本修订记录作为历史；新版主开关采用“保持 Mac 运行”。开启说明随 Computer Use 偏好与实际应用结果变化：仅后台保持运行时不得声称保持桌面会话可用；Computer Use 设置开启但实际 display assertion 失败时，不得呈现该能力已生效。设置已选中不等于运行状态已确认。

不使用“确保 Computer Use 正常运行”或“永不锁屏”：用户主动锁定、开盖自动锁定及其他系统事件仍可能中断桌面自动化。合盖时降低内置屏幕亮度与保持桌面会话可用可以同时成立。本次只修改草图文案；产品代码未修改，继续等待本项确认。
