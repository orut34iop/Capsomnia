功能关系

  • 总开关关闭：下面都是预设，不会单独生效。
  • Computer Use 选项关闭：保持电脑运行，不额外保持屏幕操作环境。
  • Computer Use 选项开启：在保持运行的基础上保留屏幕操作环境；“开盖后锁定屏幕”只在这项功能生效时可触发。
  • 电源：不是模式，也不是开关。现有代码不要求接电，拔电行为仍需本机实测。

仍可手动锁屏；定时结束、手动锁屏或开盖后锁定都可能中断屏幕自动操作。界面不会承诺“永不锁屏”或“自动化一定成功”。
